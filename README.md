# Cryptomator Free for Android

A community project exploring a free Android vault app based on Cryptomator's open-source Android application.

## Project goals

- Preserve the familiar Cryptomator interface wherever practical.
- Support local storage and supported cloud-storage workflows.
- Keep Cryptomator Hub entitlement checks and related behavior intact.
- Develop a clearly distinct app variant with its own application ID.
- Publish source code and APKs only after the build and device tests pass.

## Status

**Planning / repository bootstrap.** The upstream source has not yet been imported, and no APK is available from this repository.

## Next steps

1. Import or fork the appropriate upstream source while preserving its license and notices.
2. Review the upstream build process, licensing, and entitlement-related code.
3. Implement and test the community variant.
4. Add reproducible CI builds and test on a physical Android device.
5. Publish a release only after validation.

## Important

This is an independent community project, not an official Cryptomator release. The project must comply with the upstream license and preserve required notices.
